# UX profile

Read by the VectorLab UX skills before layout, colour, type or motion changes.

## Aesthetic

Stripe, dark. Neutral L0–L3 surfaces (`--surface-l0` … `--surface-l3`), 1px borders first,
one accent hue (`--accent` #3b82f6) for actions, links and focus. Inter at 400 / 500 / 600.

## Accessibility

WCAG 2.1 AA. Hit targets 44×44px. Visible `:focus-visible` ring on every control.

## Voice

Utilitarian and minimal. Sentence case, verb-first buttons, no blame in errors.

## Banned anti-aesthetics

Catalog defaults: glassmorphism, rainbow / multi-hue CTAs, gradient text, neon glows,
pill wrappers on static text, decorative blob backgrounds, cartoon people.

## Notes (documented exceptions)

This is a public marketing page (route type: Home / landing), not app chrome.
These are allowed here and nowhere else:

- **Hero 3D scene** (`hero-3d.js`): continuous idle motion, overshoot entrance and
  drag/throw physics. Paused off screen and in hidden tabs; a still frame for reduced motion.
- **Kinetic hero word**: cycles every 2.8s. Off for reduced motion; the full sentence is in `aria-label`.
- **Work carousel autoplay and showreel / motion clips**: content, not decoration.
  Plays only on screen; never autoplays for reduced motion.
- **Pointer tilt** (`[data-tilt]`, ≤6°) and the cursor follower: mouse only, off for reduced motion.
- **Samurai intro**: once per session, skippable, skipped for reduced motion.
- **Scroll-linked scenes** (GSAP scrub): tied to scroll position, so the motion token scale does not apply.
